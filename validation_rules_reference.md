# AssessmentCore Validation Engine Rules & Triggering Specifications

This document provides a comprehensive guide to all validation rules executed in the AssessmentCore `batch-creator` pipeline. It details how the validation engine processes rows, the severities assigned to issues, and the precise conditions under which each error message is triggered.

---

## 1. Rule Engine Overview & Severity Levels

The engine evaluates rows against registered rules in priority order. Each validation failure emits a `ValidationIssue` object containing a severity level:

- **`block` (Red)**: Critical error. Blocks the row from being exported until resolved. Marks row status as `rejected`.
- **`review` (Orange/Yellow)**: Content or structural ambiguity. Requires human review. Marks row status as `needs_review`.
- **`warning` / `caution` (Yellow)**: Non-fatal issue or recommendation. Marks row status as `caution`.
- **`info` (Blue)**: Informational notice or soft recommendation. Does not block progression.

## 2. General & Metadata Rules (`general.rules.ts`)

These rules apply universally to all questions regardless of type, or to general metadata structure.

### `REQUIRED_QUESTION_FIELD`

- **Severity**: `block`
- **Applies To**: `all` (non-`UNKNOWN` types)
- **Target Field**: `stem`, `options`, `correctAnswer`, `acceptedAnswers`
- **Triggering Conditions**:
  1. `stem` is missing or empty/whitespace only (`"Question stem is required."`)
  2. `type` is `MCQ` or `MSQ` and `options` has fewer than 2 options (`"At least 2 options are required."`)
  3. `type` is `MCQ` and `correctAnswerId` is missing/empty (`"Correct answer is required."`)
  4. `type` is `MSQ` and `correctAnswerIds` is empty (`"At least one correct answer is required."`)
  5. `type` is `TEXT_ENTRY` and `acceptedAnswers` is empty (`"At least one accepted answer is required."`)

### `UNKNOWN_QUESTION_TYPE_BLOCK`

- **Severity**: `block`
- **Applies To**: `UNKNOWN`
- **Target Field**: `type`
- **Triggering Conditions**:
  - Triggered whenever `normalizedQuestion.type === 'UNKNOWN'`, indicating column mapping failed or question type could not be inferred from options/answers.
  - **Error Message**: `"Question type could not be determined."`

### `EMPTY_ROW_WARNING`

- **Severity**: `warning`
- **Applies To**: `all`
- **Target Field**: Row root
- **Triggering Conditions**:
  - Triggered when `type === 'UNKNOWN'`, `rawStem` is empty, AND all mapped columns in `rawRow` are empty or whitespace.
  - **Error Message**: `"Row appears to be completely empty."`

### `DUPLICATE_QUESTION_ID`

- **Severity**: `block`
- **Applies To**: `all`
- **Target Field**: `questionId`
- **Triggering Conditions**:
  - Triggered when `row.metadata.questionId` is defined and matches the `questionId` of another row in the batch.
  - **Error Message**: `"Duplicate Question ID found: {questionId}"`

### `DUPLICATE_NORMALIZED_STEM_REVIEW`

- **Severity**: `review`
- **Applies To**: `MCQ`, `MSQ`, `TEXT_ENTRY`
- **Target Field**: `stem`
- **Triggering Conditions**:
  - Triggered when `q.stem` (trimmed, case-insensitive) matches the normalized stem of another valid row in the batch.
  - **Error Message**: `"This question stem is identical to another row."`

### `LATEX_STEM_DELIMITER_VALID`

- **Severity**: `review`
- **Applies To**: `MCQ`, `MSQ`, `TEXT_ENTRY`, `ORDER`
- **Target Field**: `stem`
- **Triggering Conditions**:
  - Triggered when LaTeX delimiters (`$...$`, `$$...$$`, `\(...\)`, `\[...\]`) in the question stem are unclosed, mismatched, or invalidly nested.
  - **Error Message**: Message generated by LaTeX analyzer (e.g., `"Unclosed LaTeX math delimiter '$'"`).

### `MEDIA_URL_INVALID_FORMAT`

- **Severity**: `block`
- **Applies To**: `all`
- **Target Field**: `mediaReferences[index]`
- **Triggering Conditions**:
  - Triggered when a linked image/media URL fails URI schema parsing, uses invalid file extensions, or fails URL format verification.
  - **Error Message**: Format error from media validator (e.g., `"Invalid URL format for media reference"`).

### `MARKS_INVALID`

- **Severity**: `block`
- **Applies To**: `all`
- **Target Field**: `marks`
- **Triggering Conditions**:
  - `row.scoringConfig.marks` is defined but is not a finite number, or is `<= 0`.
  - **Error Message**: `"Marks must be a finite number greater than 0."`

### `NEGATIVE_MARKS_INVALID`

- **Severity**: `block`
- **Applies To**: `all`
- **Target Field**: `negativeMarks`
- **Triggering Conditions**:
  - `row.metadata.negativeMarks` is defined but is not a finite number, or is `> 0` (must be non-positive, e.g. `-0.25` or `0`).
  - **Error Message**: `"Negative marks must be a finite number less than or equal to 0."`

### `TIME_LIMIT_INVALID`

- **Severity**: `block`
- **Applies To**: `all`
- **Target Field**: `timeLimitSeconds`
- **Triggering Conditions**:
  - `row.timeLimitConfig.timeLimitSeconds` is defined but is not a finite number or is `<= 0`.
  - **Error Message**: `"Time limit must be a finite number greater than 0 seconds."`

### `YEAR_INVALID`

- **Severity**: `warning`
- **Applies To**: `all`
- **Target Field**: `year`
- **Triggering Conditions**:
  - `row.metadata.year` is defined but is `< 1900` or `> currentYear + 5`.
  - **Error Message**: `"Unusual year value: {year}"`

## 3. MCQ Validation Rules (`mcq.rules.ts`)

Rules specific to Single Choice Multiple Choice Questions (`MCQ`).

| Rule ID                         | Severity | Target Field      | Triggering Condition & Message                                                                                                                                                                       |
| ------------------------------- | -------- | ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `MCQ_MIN_OPTIONS`               | `block`  | `options`         | Options list has `< 2` items.<br/>_Message_: `"MCQ must have at least 2 options."`                                                                                                                   |
| `MCQ_OPTION_TEXT_NOT_EMPTY`     | `block`  | `options[idx]`    | Any option has empty/whitespace text.<br/>_Message_: `"Option {label} has empty text."`                                                                                                              |
| `MCQ_OPTIONS_UNIQUE`            | `review` | `options`         | Two options have identical text (case-insensitive, trimmed).<br/>_Message_: `"Duplicate option text found in options {label1} and {label2}."`                                                        |
| `MCQ_OPTION_IDENTIFIERS_UNIQUE` | `block`  | `options`         | Duplicate option internal IDs detected.<br/>_Message_: `"Duplicate option identifier detected internally."`                                                                                          |
| `MCQ_OPTION_IDENTIFIER_VALID`   | `block`  | `options`         | Option internal ID is empty or missing.<br/>_Message_: `"Option is missing an internal identifier."`                                                                                                 |
| `MCQ_HAS_CORRECT_ANSWER`        | `block`  | `correctAnswerId` | `correctAnswerId` is null, undefined, or empty string.<br/>_Message_: `"Correct answer is required."`                                                                                                |
| `MCQ_ANSWER_IN_OPTIONS`         | `block`  | `correctAnswerId` | `correctAnswerId` does not match any option's internal ID, label (A, B, C), or option text.<br/>_Message_: `"Correct answer '{raw}' does not match any option."`                                     |
| `MCQ_ANSWER_TEXT_MATCH`         | `block`  | `correctAnswerId` | Answer text specified in raw sheet does not match any option text or label.<br/>_Message_: `"Answer text '{raw}' does not match any option."`                                                        |
| `MCQ_ANSWER_TEXT_AMBIGUOUS`     | `block`  | `correctAnswerId` | Raw answer text matches multiple options identically.<br/>_Message_: `"Answer text '{raw}' matches multiple options. Select an unambiguous option identifier."`                                      |
| `MCQ_SINGLE_CORRECT_ONLY`       | `block`  | `correctAnswerId` | `correctAnswerId` contains delimiters (`,` or `;`), indicating multiple answers were given for an MCQ.<br/>_Message_: `"MCQ must have exactly one correct answer. Found multiple delimited values."` |
| `MCQ_SHOULD_BE_MSQ_REVIEW`      | `review` | `type`            | MCQ question has multiple delimited answers in raw data. Recommends conversion to MSQ.<br/>_Message_: `"Row is marked as MCQ but answer contains multiple values. Consider changing to MSQ."`        |
| `MCQ_SUSPECT_TRUE_FALSE_REVIEW` | `info`   | `options`         | MCQ has exactly 2 options with texts "True" and "False".<br/>_Message_: `"Question has True/False options. This could be mapped to a TRUE_FALSE question type later."`                               |

## 4. MSQ Validation Rules (`msq.rules.ts`)

Rules specific to Multiple Select Questions (`MSQ`).

| Rule ID                            | Severity  | Target Field       | Triggering Condition & Message                                                                                                                                                     |
| ---------------------------------- | --------- | ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `MSQ_MIN_OPTIONS`                  | `block`   | `options`          | MSQ has `< 2` options.<br/>_Message_: `"MSQ must have at least 2 options."`                                                                                                        |
| `MSQ_HAS_CORRECT_ANSWERS`          | `block`   | `correctAnswerIds` | `correctAnswerIds` array is empty or missing.<br/>_Message_: `"At least one correct answer is required for MSQ."`                                                                  |
| `MSQ_ANSWER_IDENTIFIER_VALID`      | `block`   | `correctAnswerIds` | An entry in `correctAnswerIds` is empty/whitespace.<br/>_Message_: `"Correct answer contains an empty identifier."`                                                                |
| `MSQ_OPTION_IDENTIFIERS_UNIQUE`    | `block`   | `options`          | Duplicate option internal IDs detected.<br/>_Message_: `"Duplicate option identifier detected internally."`                                                                        |
| `MSQ_OPTIONS_UNIQUE`               | `review`  | `options`          | Duplicate option text found across options.<br/>_Message_: `"Duplicate option text found in options {label1} and {label2}."`                                                       |
| `MSQ_CORRECT_ANSWERS_IN_OPTIONS`   | `block`   | `correctAnswerIds` | One or more answer IDs in `correctAnswerIds` do not correspond to any option.<br/>_Message_: `"Correct answers [{invalid}] do not match any option."`                              |
| `MSQ_MIXED_IDENTIFIER_MODE`        | `block`   | `correctAnswerIds` | Raw answer mixes labels (e.g. `A`) and full option text (e.g. `Option Text`).<br/>_Message_: `"Answers mix option identifiers and option text. Use one answer mode consistently."` |
| `MSQ_NO_DUPLICATE_CORRECT_ANSWERS` | `warning` | `correctAnswerIds` | Raw answer contains duplicate entries for the same option (e.g., `A, A, B`).<br/>_Message_: `"Correct answers contain duplicate entry '{token}'."`                                 |
| `DELIMITER_FORMAT_FOR_MSQ`         | `warning` | `correctAnswerIds` | Answer string uses irregular delimiters or spacing.<br/>_Message_: `"Irregular delimiter format in MSQ answer."`                                                                   |

## 5. Text Entry / Numeric Rules (`textEntry.rules.ts`)

Rules specific to Fill-in-the-Blank and Numeric response questions (`TEXT_ENTRY`).

| Rule ID                                       | Severity  | Target Field       | Triggering Condition & Message                                                                                                                                                                       |
| --------------------------------------------- | --------- | ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `TEXT_ENTRY_HAS_ANSWER`                       | `block`   | `acceptedAnswers`  | `acceptedAnswers` array is empty or missing.<br/>_Message_: `"At least one accepted answer is required."`                                                                                            |
| `TEXT_ENTRY_ACCEPTED_ANSWERS_NOT_EMPTY`       | `block`   | `acceptedAnswers`  | Any entry in `acceptedAnswers` is empty or whitespace.<br/>_Message_: `"Accepted answers cannot be empty strings."`                                                                                  |
| `TEXT_ENTRY_MULTIPLE_ANSWERS_DELIMITER_VALID` | `warning` | `acceptedAnswers`  | An accepted answer string contains an unparsed pipe (`\|`) symbol.<br/>_Message_: `"Answer '{ans}' contains a pipe '\|'. Make sure delimiters were parsed correctly."`                               |
| `TEXT_ENTRY_CASE_POLICY_DEFINED`              | `review`  | `caseSensitive`    | Text mode question does not explicitly specify case sensitivity policy.<br/>_Message_: `"Case sensitivity policy should be explicitly defined for text mode."`                                       |
| `TEXT_ENTRY_TRIM_POLICY_DEFINED`              | `review`  | `trimPolicy`       | Trim policy (`trim` vs `preserve`) is undefined.<br/>_Message_: `"Trim whitespace policy should be explicitly defined."`                                                                             |
| `TEXT_ENTRY_NUMERIC_ANSWER_VALID`             | `block`   | `acceptedAnswers`  | Question mode is `numeric`, but an accepted answer cannot be parsed as a number (`Number(ans)` is `NaN`).<br/>_Message_: `"Numeric mode selected, but answer '{ans}' cannot be parsed as a number."` |
| `TEXT_ENTRY_NUMERIC_TOLERANCE_VALID`          | `block`   | `numericTolerance` | Question mode is `numeric`, and `numericTolerance` is `< 0` or `NaN`.<br/>_Message_: `"Numeric tolerance must be a non-negative number."`                                                            |
| `TEXT_ENTRY_UNIT_POLICY_VALID`                | `warning` | `units`            | Question mode is `numeric`, and `units` property is an empty string.<br/>_Message_: `"Units defined but empty string provided."`                                                                     |
| `TEXT_ENTRY_FORMULA_FORMAT_VALID`             | `block`   | `acceptedAnswers`  | Question mode is `formula`, and an accepted answer is empty.<br/>_Message_: `"Formula answer cannot be empty."`                                                                                      |
| `TEXT_ENTRY_LATEX_VALID`                      | `warning` | `acceptedAnswers`  | Question mode is `formula`, and an accepted answer has odd/unclosed `$` LaTeX delimiters.<br/>_Message_: `"Unclosed LaTeX delimiter detected in formula answer '{ans}'."`                            |

## 6. Order / Sequencing Rules (`order.rules.ts`)

Rules specific to Ordering / Sequence questions (`ORDER`).

| Rule ID                      | Severity | Target Field         | Triggering Condition & Message                                                                                                                                                                              |
| ---------------------------- | -------- | -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ORDER_MIN_OPTIONS`          | `block`  | `options`            | Ordering question has `< 2` options.<br/>_Message_: `"Ordering question must have at least 2 options to order."`                                                                                            |
| `ORDER_HAS_CORRECT_SEQUENCE` | `block`  | `correctSequenceIds` | `correctSequenceIds` is empty OR its length does not equal `options.length`.<br/>_Message_: `"Correct sequence length ({seqLen}) must match the number of options ({optLen})."`                             |

## 7. Export Readiness Gate Rules (`exportReadiness.rules.ts`)

These final checks execute before generating output packages (QTI 2.1, QTI 3.0, JSON).

1. **`nonEmptyBatch`** (`block`): Batch contains 0 validated rows.
2. **`noRejectedRows`** (`block`): One or more rows have status `rejected` (unresolved `block` issues).
3. **`noUnknownRows`** (`block`): One or more rows have `type === 'UNKNOWN'`.
4. **`reviewRowsNeedApproval`** (`warning`): Rows with `needs_review` status exist and require user acknowledgment.
5. **`qtiCompatibility`** (`warning`): Media mode set to `keep_public_url` or partial marking used with QTI 2.1.
6. **`qti30Compatibility`** (`block`): Formula-mode `TEXT_ENTRY` question present when target is `qti_3_0`.
7. **`identifierIntegrity`** (`block` / `warning`): Question ID is missing, duplicated, or contains non-XML-safe characters.
